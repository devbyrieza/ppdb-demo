PASAL 3 — DETAIL PEMELIHARAAN &amp; WHATSAPP GATEWAY



3.1  Cakupan Layanan Tahunan

4 | Sertifikat Keamanan SSL/HTTPS | SUDAH TERMASUK (GRATIS) | Pemasangan protokol HTTPS terenkripsi untuk mengamankan data calon santri dan transaksi pendaftaran dari intersepsi pihak luar.
5 | Backup Data &amp; Pemeliharaan Rutin | SUDAH TERMASUK | Backup database berkala secara otomatis, monitoring keaktifan server 24/7, serta perbaikan jika terjadi error sistem atau gangguan server.



3.2  Spesifikasi, Keamanan &amp; Isolasi Data

• Lokasi Server: Server ditempatkan pada infrastruktur VPS KVM Hostinger berkinerja tinggi yang berlokasi di Jakarta untuk kecepatan akses maksimal dari seluruh wilayah Indonesia.

• Isolasi Sistem (Docker): Database dan file sistem setiap pesantren diisolasi secara mandiri menggunakan teknologi Docker Container. Data tidak akan saling bercampur atau dapat diakses oleh pihak luar, menjamin keamanan dan privasi 100%.



3.3  Mekanisme Pembayaran Tahunan

Guna menjamin kemudahan administratif dan kelancaran operasional pesantren:
• Klien tidak perlu melakukan pembayaran terpisah kepada berbagai vendor pihak ketiga.

PASAL 4 — FITUR EKSKLUSIF YANG TERMASUK DALAM PAKET



Seluruh fitur canggih berikut sudah termasuk dalam biaya jasa pembuatan:

4.1  Fitur Pendaftaran &amp; Manajemen Pendaftar

• Halaman pendaftaran online (formulir berjenjang, lengkap, dan responsif)

• Sistem login dashboard mandiri untuk calon santri/wali

• Upload dokumen persyaratan (Foto, KK, Akta, Ijazah, dll.)

• Cetak Bukti Pendaftaran otomatis (PDF)

• Status tracking pendaftaran secara real-time

• Manajemen gelombang / periode kuota pendaftaran

4.2  Sistem Seleksi &amp; Ujian (CBT Terintegrasi)

• Sistem Ujian CBT (Computer Based Test) Terintegrasi langsung di website (Soal Pilihan Ganda &amp; Likert)

• Cetak Kartu Peserta Ujian / ID Card Seleksi (PDF)

• Dashboard khusus Penguji (Input nilai ujian offline: Al-Qur’an, Wawancara Santri, Wawancara Ortu)

• Sistem Matriks Kelulusan Otomatis (otomatis merekomendasikan DITERIMA/CADANGAN/DITOLAK berdasarkan pembobotan nilai)

4.3  Sistem Manajemen Multi-Peran (Hak Akses Spesifik)

• Dashboard Admin Super (Akses ke seluruh pengaturan dan statistik)

• Dashboard Admin Keuangan (Khusus validasi bukti pembayaran)

• Dashboard Admin Berkas (Khusus verifikasi kelengkapan dokumen)

• Dashboard Penguji / Pewawancara (Akses dibatasi hanya untuk input nilai ujian)

4.4  Fitur Notifikasi &amp; Komunikasi Cerdas

• Notifikasi WhatsApp otomatis ke pendaftar (Tagihan, Jadwal Ujian, Pengumuman Kelulusan)

• Notifikasi WhatsApp ke panitia saat ada pendaftaran/pembayaran baru

• Fitur Broadcast WhatsApp Masal dari Dashboard Admin ke seluruh pendaftar

4.5  Fitur Laporan, Analitik &amp; Keuangan

• Dashboard rekapitulasi data pendaftar &amp; laporan keuangan

• Audit Hasil Seleksi &amp; Ujian secara transparan

• Ekspor Laporan Data lengkap ke format Excel (XLSX) / CSV Profesional

• Statistik visual grafik pendaftar berdasarkan asal daerah, jenjang, dll.

4.6  Fitur Teknis, Keamanan &amp; Layanan Pendampingan

• Hosting di Cloud Server VPS KVM berkinerja tinggi (Jakarta Data Center) — database diisolasi per-pesantren dengan teknologi Docker/Containerization

• SSL/HTTPS aktif (koneksi aman terenkripsi) &amp; Domain custom (.com)

• Auto-Backup database berkala

• Tampilan elegan dan responsif (Mobile, Tablet, Desktop)

• Instalasi, konfigurasi server, &amp; pelatihan sistem kepada panitia PPDB

• Pelatihan sistem untuk admin/panitia (via video call)

• Dokumentasi panduan penggunaan (modul tertulis)

• Pendampingan teknis gratis selama masa garansi

PASAL 7 — HAK KEKAYAAN INTELEKTUAL (HKI)



Seluruh kode program (source code), desain, dan sistem yang dikembangkan oleh pengembang tetap menjadi hak milik penuh pengembang. Pesantren diberikan hak pakai (lisensi) seumur hidup yang mencakup hak untuk melihat, memodifikasi, dan menggunakan source code untuk kebutuhan internal pesantren saja.Tidak diperkenankan mengkloning, memperjual-belikan, dan memberikan akses code kepada pihak lain.

Pesantren diperbolehkan melakukan modifikasi internal tanpa izin tertulis tambahan, namun tidak diperbolehkan mendistribusikan atau menggunakan source code untuk pesantren/institusi lain. Apabila ingin hak milik penuh, dapat dibahas secara terpisah dengan biaya tambahan. 
Catatan: Library, framework, dan komponen open-source yang digunakan tetap mengikuti lisensi masing-masing penyedianya.
