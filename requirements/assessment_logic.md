# Assessment Logic & Scoring Standards

## 1. Grading Scale (General)
Used for all components (Akademik, Quran, Wawancara, Kesiapan).

| Score Range (0-100) | Grade | Status |
| :--- | :--- | :--- |
| **85 - 100** | **A** | Sangat Baik (Lulus) |
| **70 - 84** | **B** | Baik (Lulus) |
| **55 - 69** | **C** | Cukup (Dipertimbangkan) |
| **40 - 54** | **D** | Kurang (Tidak Lulus) |
| **< 40** | **E** | Sangat Kurang (Tidak Lulus) |

## 2. Weighting & Passing Logic (Bobot Kelulusan)
Total Score = Weighted Average of 5 Components.

| Component | Weight |
| :--- | :--- |
| **Seleksi Akademik** | 30% |
| **Tes Al-Quran** | 30% |
| **Seleksi Kepribadian** | 10% |
| **Seleksi Kesiapan** | 10% |
| **Wawancara (Santri & Ortu)** | 20% |

**Decision Rule:**
- **LULUS**: Final Grade A or B.
- **CADANGAN**: Final Grade C.
- **TIDAK LULUS**: Final Grade D or E.
- *Critical Failure*: If **Tes Al-Quran** is Grade E, automatically **TIDAK LULUS** regardless of Total Score.

## 4. Scoring Logic (Non-Akademik)

### Seleksi Kepribadian (100 Soal A/B)
**Logic**: "Positive Character" matching.
- We will define a key where choice A or B represents the "Pesantren-aligned" trait (Discipline, Honesty, Resilience).
- Score = (Matches / 100) * 100.

### Seleksi Kesiapan (15 Soal Skala 1-5)
- **Score** = (Sum of Answers / 75) * 100.
- Range 1-5 maps to linear score.

### Tes Al-Quran & Wawancara
- Input is already in Grade (A/B/C) or raw score.
- If raw score (1-100), use grading scale.
- If Recommendation (A/B/C), map to: A=95, B=80, C=60, D=40, E=20.
