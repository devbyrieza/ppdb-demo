# Workspace Rules

1. **Cross-Project Syncing**: Any change, modification, fix, or update made in any SPMB project (e.g. `alandalus-alimam`) MUST also be replicated, executed, and synced across all SPMB projects:
   - `alandalus-alimam`
   - `alandalus-ululalbaab`
   - `andalus-pusat-putra`
   - `andalus-pusat-putri`
   - `template-demo` (or `ppdb-demo`)
   Always ensure consistency across all these repositories and commit/push changes simultaneously.
